OxiGuitar packages

The apt, dnf and Flatpak repositories of OxiGuitar, a free guitar tablature viewer, editor and player, and of its plugins. Each package is the one attached to the release of its own repository; this site only signs and lists them.

Debian, Ubuntu and relatives (apt)

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL @URL@/oxiguitar.gpg -o /etc/apt/keyrings/oxiguitar.gpg
sudo curl -fsSL @URL@/oxiguitar.sources -o /etc/apt/sources.list.d/oxiguitar.sources
sudo apt update
sudo apt install -o APT::Install-Suggests="true" oxiguitar

Plugins are packages named oxiguitar-guitarpro, oxiguitar-midi and so on. oxiguitar recommends the Guitar Pro, MIDI, ALSA and PipeWire ones, which apt installs with it, and suggests oxiguitar-nam (amp models) and oxiguitar-eq (an equalizer), which the option -o APT::Install-Suggests="true" installs too. The MIDI plugin suggests oxiguitar-bettersounds-soundfonts, the recommended sound sets: installing it asks whether to download them now (about 1.2 GB; no is the default), and oxiguitar-install-sounds lets you choose which ones, any time. apt upgrade keeps all of them current.

Fedora and relatives (dnf)

sudo curl -fsSL @URL@/oxiguitar.repo -o /etc/yum.repos.d/oxiguitar.repo
sudo dnf install oxiguitar

Any Linux (Flatpak)

flatpak remote-add --if-not-exists oxiguitar @URL@/flatpak/oxiguitar.flatpakrepo
flatpak install oxiguitar io.github.mateusrdp.OxiGuitar
flatpak install oxiguitar io.github.mateusrdp.OxiGuitar.Plugin.guitarpro io.github.mateusrdp.OxiGuitar.Plugin.midi io.github.mateusrdp.OxiGuitar.Plugin.pipewire

Or open io.github.mateusrdp.OxiGuitar.flatpakref in a software centre. Each plugin is an add-on of its own, io.github.mateusrdp.OxiGuitar.Plugin. and its short name (guitarpro, midi, alsa, pipewire, nam, eq and so on); none comes with the app on its own. The runtime comes from Flathub, which Flatpak adds if it isn't there. flatpak update keeps all of them current. Sound sets go in the Flatpak's own folder: the sound-set installer fills it.

The signing key

All three repositories are signed with one key, fingerprint @FINGERPRINT@: oxiguitar.asc (armoured) or oxiguitar.gpg (binary). Check the fingerprint against the one in the repository's README.

Nothing here is ever downloaded by OxiGuitar itself. The list of packages in this build is in packages.txt.
