OxiGuitar packages

The apt and dnf repositories of OxiGuitar, a free guitar tablature viewer, editor and player, and of its plugins. Each package is the one attached to the release of its own repository; this site only signs and lists them.

Debian, Ubuntu and relatives (apt)

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL @URL@/oxiguitar.gpg -o /etc/apt/keyrings/oxiguitar.gpg
sudo curl -fsSL @URL@/oxiguitar.sources -o /etc/apt/sources.list.d/oxiguitar.sources
sudo apt update
sudo apt install -o APT::Install-Suggests="true" oxiguitar

Plugins are packages named oxiguitar-guitarpro, oxiguitar-midi and so on. oxiguitar recommends the Guitar Pro, MIDI, ALSA and PipeWire ones, which apt installs with it, and suggests oxiguitar-nam (amp models), which the option -o APT::Install-Suggests="true" installs too. apt upgrade keeps all of them current.

Fedora and relatives (dnf)

sudo curl -fsSL @URL@/oxiguitar.repo -o /etc/yum.repos.d/oxiguitar.repo
sudo dnf install oxiguitar

The signing key

Both repositories are signed with one key, fingerprint @FINGERPRINT@: oxiguitar.asc (armoured) or oxiguitar.gpg (binary). Check the fingerprint against the one in the repository's README.

Nothing here is ever downloaded by OxiGuitar itself. The list of packages in this build is in packages.txt.
